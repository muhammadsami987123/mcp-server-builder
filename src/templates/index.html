See It In Action

Example: Building an MCP server from a REST API

Input: API Documentation URL
https://api.example.com/docs
→
Output: MCP Server
from mcp.server import Server
from mcp.types import Tool

server = Server("example-api-mcp")

@server.tool()
def list_users(limit: int = 10) -> str:
    """List users from the Example API"""
    response = api_client.get("/users", params={"limit": limit})
    return json.dumps(response.json())

@server.tool()
def get_user(user_id: str) -> str:
    """Get a specific user by ID"""
    response = api_client.get(f"/users/{user_id}")
    return json.dumps(response.json())

Frequently Asked Questions

What is MCP?

Model Context Protocol is an open standard that allows AI models to interact with external tools and data sources through a standardized interface.

Do I need to upload files?

No. Just paste a URL to your API documentation. We automatically discover and parse OpenAPI specs, Swagger definitions, and other documentation formats.

What if my API doesn't have OpenAPI?

Our system can parse regular HTML/Markdown documentation and extract API information from it using AI analysis.

Can I customize the generated server?

Absolutely. Review the generated tools, select which ones to include, customize naming, and regenerate as needed.

Is the generated code production-ready?

Yes. Generated servers include error handling, proper async patterns, environment configuration, and are validated for correctness.

How does authentication work?

API authentication is configured via environment variables. Your generated server handles Bearer tokens, API keys, and other auth methods securely.
