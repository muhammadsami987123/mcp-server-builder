MCP Server Builder API Documentation

Overview

The MCP Server Builder API allows you to programmatically discover REST APIs, design MCP tools using AI, and generate complete MCP server implementations.

Endpoints

POST /api/analyze

Analyze and discover API from a URL

Request

{
  "url": "https://api.example.com"
}

Response

{
  "success": true,
  "api": {
    "name": "Example API",
    "description": "...",
    "version": "1.0.0",
    "endpoints": [...]
  },
  "analysis": {
    "endpoint_count": 15,
    "methods": {...},
    "authentication": {...}
  },
  "errors": []
}

POST /api/design-tools

Design MCP tools from discovered API

Request

{
  "api": { ... },
  "max_tools": 10,
  "custom_name": "my_api_mcp"
}

Response

{
  "success": true,
  "design": {
    "server_name": "my_api_mcp",
    "tools": [
      {
        "name": "get_users",
        "description": "Retrieve all users",
        "method": "GET",
        "path": "/users"
      }
    ]
  },
  "tool_count": 5
}

POST /api/generate

Generate complete MCP server code

Request

{
  "design": { ... },
  "validate": true
}

Response

{
  "success": true,
  "project_id": "uuid-here",
  "files_count": 12,
  "file_tree": {...},
  "validation": {...}
}

GET /api/project/{project_id}

Get project details

GET /api/project/{project_id}/tools

Get MCP tools for a project

GET /api/project/{project_id}/files

Get file tree for a project

GET /api/project/{project_id}/download

Download generated server as ZIP

GET /api/projects

List all projects (history)

Query Parameters

Parameter Type Description
limit integer Max results (default: 20, max: 100)
offset integer Skip first N results (default: 0)

Security

  • SSRF Protection: Blocks access to private IP ranges and localhost
  • Request Timeout: 20 seconds maximum per request
  • Response Size: Maximum 10MB per response
  • Redirect Limit: Maximum 5 redirects per request

Error Handling

All errors return appropriate HTTP status codes and include error details:

{
  "detail": "Error message describing what went wrong"
}

Environment Variables

Variable Required Description
OPENAI_API_KEY Yes OpenAI API key for tool design
